# Contributing to VoiceLingo

Thank you for your interest in contributing to **VoiceLingo**! We welcome contributions from developers, translators, and audio enthusiasts.

## How to Contribute

### Reporting Bugs
If you find a bug:
1. Open an issue on GitHub.
2. Provide a clear description of the issue, steps to reproduce, and your browser/OS version (e.g. Chrome on Android, Safari on iOS).

### Feature Requests & Language Suggestions
Have an idea for a new language, improved translation lexicon, or UI refinement?
- Open a GitHub issue or email Waseem Asif at `wasimasif761@gmail.com`.

### Submitting Pull Requests (PRs)
1. Fork the repository.
2. Create your feature branch: `git checkout -b feature/amazing-feature`.
3. Commit your changes: `git commit -m 'feat: add amazing feature'`.
4. Run verification commands:
   ```bash
   npm run lint
   npm run build
   ```
5. Push to the branch: `git push origin feature/amazing-feature`.
6. Open a Pull Request.

## Code Standards
- Use TypeScript with strict typing.
- Style with Tailwind CSS.
- Ensure all speech APIs fail gracefully when permissions or network are unavailable.
- Maintain PWA compliance and offline fallback support.
